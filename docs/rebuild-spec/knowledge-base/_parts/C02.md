## Entries

### C02-001: A file uploaded from a Windows browser can carry backslash path tricks.
- What was going on: A Windows browser can send an upload name like "..\..\evil.wav"; a server on Linux that splits names only on "/" keeps the traversal shape.
- What the product must do: Every uploaded file name is cut to its last part on both "/" and "\" before it is used, so no upload can name a path outside its folder.
- Kind: 3
- Capability: music
- Found by: a test
- Date: 2026-08-17
- State: fixed and live
- Sources: C-cc-e607fbe3a

### C02-002: The NAS tailnet service gave up after 60 s and minted new login links.

- What the product must do: A first-time tailnet sign-in on the NAS shows one stable login link until the owner completes it, and publishing is set only after sign-in succeeds.
