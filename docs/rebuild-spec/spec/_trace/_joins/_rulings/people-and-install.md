## Questions for the owner

### Q1: When an editor signs in on a new computer, does it start syncing straight away, or wait until an admin approves it?
- Findings: accounts-privacy-legal F2, editor-app F1
- The two sides: one piece says signing in on the computer is all it takes, because the admin already let that person in; four others (the dashboard, syncing, the editor's app and the server set-up) have the new computer wait on a list until an admin approves it and confirms whose it is, and the editor's finish page says "waiting for your admin to approve this computer".
- Options: A: signing in is enough; the computer is the signed-in person's and gets their projects within about a minute, the admin sees it appear and can end it ("a device was lost"). B: the computer waits until an admin approves it under its owner (filled in from the sign-in), and nothing syncs until then.
- Recommend: A, because the admin already decided the person may come in and the sign-in already says whose computer it is, so approval asks the admin to confirm what is known, and it is one list, one warning and one waiting page fewer.
- What you would notice: with A a new or reinstalled laptop syncs minutes after the editor signs in, with no admin step; with B the editor waits until an admin presses approve.
