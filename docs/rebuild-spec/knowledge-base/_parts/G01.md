# Knowledge base part G01

## Entries

### G01-001: Resolve's scripting died for the whole session after something connected during launch
- What was going on: Resolve starts its script server (fuscript, TCP port 1144) 90-470 s into launch; a client connecting before Resolve registers with it kills scripting for that session, for every program.
- What the product must do: Connect to Resolve only when the TCP table shows fuscript listening on 1144 and an established connection to it owned by Resolve; connect anyway only if the table is unreadable.
- Kind: 1a
- Capability: resolve-on-the-editors-computer
- Found by: real use
- Date: 2026-08-21
- State: a standing rule
- Sources: G-cc-016, G-tc-009, G-cc-022
