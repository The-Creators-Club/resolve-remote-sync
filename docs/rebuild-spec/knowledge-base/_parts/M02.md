### M02-001: A Mac spells accented file names differently, so synced files looked missing forever.
- What was going on: macOS hands back file names decomposed (NFD) while Windows and the NAS use composed (NFC), so 12 files with accents showed as owed for a day though on disk.
- What the product must do: Every path comparison between machines treats the NFC and NFD spellings as equal, while files are opened, renamed or deleted by their exact bytes.
- Kind: 1a
- Capability: sync
- Found by: real use
- Date: 2026-08-28
- State: fixed and live
- Sources: M-cc-mac-filenames-are-nfd

### M02-002: Resolve's scripting dies for the whole session if anything connects during its launch.
- What was going on: Resolve starts its script server 90-470 s into launch; a client connecting in the half second before Resolve registers kills it, and a connect attempt with no server blocks about 4 s.
- What the product must do: The app connects to Resolve's scripting only once the script server is listening and Resolve is connected to it, so a Resolve launched beside the app keeps scripting.
- Kind: 1a
- Capability: resolve-on-the-editors-computer
- Found by: real use
