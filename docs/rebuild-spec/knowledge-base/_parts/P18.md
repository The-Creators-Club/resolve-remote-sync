# Knowledge base part P18

## Entries

### P18-001: A camera card in a CFexpress Type B reader was not seen as a card.
- What was going on: Windows presents a CFexpress Type B reader's card, and a Blackmagic camera's SSD, as a fixed disk, so a check for removable drives missed it and copies were refused.
- What the product must do: A fixed drive with a camera's folder layout is detected, listed and copyable as a camera card; the system disk is never treated as one.
- Kind: 1a
- Capability: footage-sorter-and-camera-cards
- Found by: real use
- Date: 2026-11-10
- State: fixed and live
- Sources: P-03745, P-03816, P-03817, C-cc-7ac37ed3c, C-cc-15bbde065

### P18-002: A card that mounts slowly was ignored for minutes because it first looked empty.

### P18-006: One decode run reading many points of one file grew to tens of gigabytes.
