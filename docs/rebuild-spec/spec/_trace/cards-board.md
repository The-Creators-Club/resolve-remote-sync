## Questions for the owner

### cards-board-Q1: When an episode's footage is processed, should the first sort run straight into the themes the assistant proposes, or wait for you to pick the themes first?
- Kind: differs
- Today: the assistant proposes themes, a person ticks which to keep (against a suggested number, 12 or 18 with no rule), renames and adds, and only then is the sort run. Your standing rule from real use says the same (sort only into themes you picked). Your requirements for the new build say every step of processing runs on its own and the first sort is its last automatic step, with the themes overridable afterwards.
- Options: A: sort on its own into the proposed themes; the proposal stays beside the board, and you drop, rename or add themes and ask for the sort again (replacing it while you have not arranged anything, and only as proposals once you have). B: processing stops at the proposal and the board waits until you pick themes.
- Recommend: A, because it is what your requirements ask for (nothing waits for a person) and it still lets you choose themes before you start arranging.
- Changes for a person: with A, a finished episode opens already sorted and you prune themes; with B, it opens on a list of themes to tick and the board is empty until you do.
- Text assumes: A
- Items: 41-034, 42-036, 43-006
- Covers: 42-Q6, U-42-7

### cards-board-Q2: When a later interview is added to a board, should its speaker always take the colour remembered for that person, even if the board shows them in another?
- Kind: differs
- Today: an added interview takes the colour that speaker's cards already have on this board, or the first colour unused on the board, so a person could end up one colour on the board and another on their clips and cuts.
- Options: A: one colour per person everywhere, always the remembered one (changed only by you, everywhere at once). B: the board's colour wins on that board.
- Recommend: A, because one colour per person is one rule with nothing to reconcile.
- Changes for a person: with A, a speaker's colour never differs between board, clips and cuts; with B, it can.
- Text assumes: A
- Items: 43-012, 43-004, 43-005
- Covers: 43-Q3

### cards-board-Q3: Should the board recognise "Personal Stories" and "Ending" in any letter case when putting themes in story order?
- Kind: differs
- Today: a new board recognises the two names in any letter case, but the quick "story order" action on a board in use recognises them only with exact capitals. The order itself (Personal Stories first, Ending last) is already your rule.
- Options: A: any letter case everywhere. B: exact capitals only.
- Recommend: A, because a theme called "ending" not being moved would be unexplained.
- Changes for a person: with A, a theme named "ending" goes last like "Ending"; with B, it stays where it was.
- Text assumes: A
- Items: 43-007, 43-015
- Covers: 43-Q6

### cards-board-Q4: When a change empties a theme, should the theme disappear by itself, or stay as an empty column until you remove it?
- Kind: other
- Today: carving a new theme out of chosen cards removes any theme it empties and says "'<name>' is now empty - removing the group", while a theme the first sort leaves empty is shown, empty.
- Options: A: an emptied column stays, and you delete it by hand. B: an emptied column disappears with a message, with no way to keep it.
- Recommend: A, because a hand-worked board should only lose a column when you remove it, and it needs no extra rule.
- Changes for a person: with A, empty columns can pile up until you delete them; with B, a column you meant to refill can vanish.
- Text assumes: A
- Items: 43-014, 43-013, 43-006
- Covers: 43-Q9

### cards-board-Q5: When the story check is run again, should its report replace the previous one, or be kept as a new dated report beside it?
- Kind: other
- Today: the instruction is only never to overwrite silently, and an earlier report is read first to say what changed; whether the new one replaces it or sits beside it is not decided.
- Options: A: every run makes a new dated report, the newest shown first, earlier ones kept. B: the new report replaces the old one after saying what changed.
- Recommend: A, because nothing is ever lost and "what changed" can always be checked against the earlier report.
- Changes for a person: with A, the episode collects one report per run; with B, there is only ever one.
- Text assumes: A
- Items: 43-022, 43-019
- Covers: 43-Q7, U-43-5

### cards-board-Q6: When a board becomes a cut, should every theme also get an empty shelf category of the same name after the cut?
- Kind: unreachable
- Today: every section not otherwise set aside also gets an empty shelf category of the same name, and nobody can turn that off.
- Options: A: keep it, always. B: cut it: only set-aside groups with cards (and "Uncategorised") become shelf categories. C: make it a choice at hand-over.
- Recommend: B, because the set-aside groups already give each theme its shelf when it has something on it, and empty categories are clutter.
- Changes for a person: with A, the editor's shelf lists every section name, empty or not; with B, only categories that hold cards.
- Text assumes: A, as the items describe it, until you decide
- Items: 43-039
- Covers: 43-Q8

### cards-board-Q7: Should a section's colour in the cut be counted by its position among all the board's columns, or only among the sections that play?
- Kind: other
- Today: each section takes a colour from a fixed rotation by its position, Blue first, and the hand-over to the editing program and the cut list can count positions differently, so markers in the editing program and the editor's sections may disagree.
- Options: A: count only the sections that play, so the cut and the hand-over always agree. B: count every column, set-aside ones included.
- Recommend: A, because the colours a person compares are those of the sections that play.
- Changes for a person: with A, a section keeps the same colour in the editor and in the editing program; with B, a set-aside column shifts the colours after it.
- Text assumes: the rotation by position, Blue first, without saying which positions count
- Items: 43-039
- Covers: 43-Q4

### cards-board-Q8: When another interview of an episode finishes processing after you have started arranging its board, should the product propose places for its paragraphs, or only put the transcript beside the board for you to drag from?
- Kind: other
- Today: a later interview is added by a step a person runs by hand, naming one theme or listing which paragraphs go to which theme, with a preview; nothing is proposed.
- Options: A: its paragraphs arrive as proposals at the end of the themes they fit; nothing else moves until you take them. B: nothing is proposed; the transcript appears beside the board with its paragraphs marked as not yet on it.
- Recommend: A, because your requirements make sorting the last automatic step of processing, and proposals never disturb your arrangement.
- Changes for a person: with A, new cards wait on the board to be taken or declined; with B, you drag every one in yourself.
- Text assumes: A
- Items: 42-046, 43-011, 43-012

## Conflicts between an item and a lesson

- BRD-028 | 41-034, 42-035 | the items cap the proposal at 25 themes (a page says 15); the lesson says at most 30. Wrote 30.
- BRD-028 | 41-034, 42-036 | the lesson (a ruling) says the owner picks themes before any sort; the owner's requirements say the first sort is automatic and overridable. Wrote the owner's requirements, and asked cards-board-Q1.
- BRD-038 | 43-008, 42-042, 42-044 | the items group a theme's cards speaker by speaker in short sub-columns; the lesson forbids one-interviewee runs and orders by argument. Wrote the lesson, so the 8-or-10 card sub-column height no longer arises.
- BRD-024 | 42-039, 41-035 | the items place a question in its answer's theme directly above the answer; the lesson says a first sort sets questions aside. Wrote: set aside in the set-aside group of the answer's theme, kept, never dropped.
- BRD-026 | 43-016 | the item estimates running time from text (3.6 Chinese characters or 18.5 English characters a second) until timed; the lesson requires real played durations. Wrote real durations from the timed words, with "not known" for a card not yet timed.
- BRD-006 | 43-039 | the item replaces an existing cut list when asked; the lesson requires a previewed merge, never an overwrite. Wrote the merge.
- BRD-039 | 43-021, 43-017 | the bridge ranking accepts an interviewer question as a last resort; the lesson says a question never bridges. Wrote never.
- BRD-007 | 41-036 | the item has a shoot's paragraphs divided among episodes by hand before themes; the lesson gives each episode a story brief and lets a paragraph sit on both boards as crossover. Wrote the lesson.
- owner's requirements | 43-039 | the item reports cards matched "only loosely" by their words; the owner's requirements tie every card to its words directly, never by matching text. Left loose matching out.
- owner's requirements | 43-024, 43-027, 43-037 | the items keep the notes as a separate structure-notes document; the owner's requirements put a notes place on the board. Wrote the notes on the board, keeping what the tidy achieves.
