Read 2026-11-24 in the Timeline Cards editor and the dashboard's episode
list as they run today.

- cards-editor-1 F2: a word tool pressed for a card that is not in the cut
  is refused with "That card is not in the cut, so the lane cannot act on
  its words." So it refuses. By the settler's own rule (a button that can
  only refuse is a dead control, page 26.5 A): cards-editor-3 offers on a
  shelf card only the Start and End buttons and Copy original;
  cards-editor-1 keeps the sentence for the remaining case (a card that
  left the cut between the press and the act).
- cards-editor-1 F5: a dragged edge is pulled to the nearest safe cut point
  when it is within 9 pixels of it (16 on a touch screen); holding Alt drags
  free. The safe points are aid 4's, so with aid 4 off nothing snaps. There
  is no "nearest fitting safe gap within 2.5 s" rule for a drag.
  cards-editor-1 states this one rule in both places and cards-editor-3's
  aid 4 row matches.
- cards-editor-5 F3 and F4: with the editor in use, the list of episodes
  shows no occupants, no "<who> was last in N min ago" and no Close: nothing
  is held open on the server, so there is nothing to close. Those lines
  belonged to the page the editor replaced. cards-editor-4 drops the
  sentence about who was last in an episode and about closing one;
  cards-editor-5 adds nothing.
