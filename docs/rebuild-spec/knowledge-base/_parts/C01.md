# Knowledge base part C01

## Entries

### C01-001: A NAS share with restricted permissions refuses permission changes, stalling sync.
- What was going on: On a NAS dataset in restricted ACL mode, changing a file's or folder's permissions is refused, so a sync that set permissions per folder stalled at its temporary-file stage.
- What the product must do: Sync onto the NAS never depends on changing file or folder permissions, and transfers complete on a restricted-ACL share.
- Kind: 1a
- Capability: sync
- Found by: real use
- Date: 2026-07-22
- State: fixed and live
- Sources: C-cc-6a650faad, C-cc-8cb78ae2a
