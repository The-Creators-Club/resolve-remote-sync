# Knowledge base part L03

### L03-001: Moving a clip failed on Windows while Resolve had it open
- What was going on: On Windows, Resolve holds its media files open in a way that refuses rename or move until the project closes or Resolve quits.
- What the product must do: Moving, renaming or replacing a file Resolve holds open is retried later, never treated as final, and the editor is told closing Resolve will let it finish.
- Kind: 1a
- Capability: resolve-on-the-editors-computer
- Found by: reading the code
- Date: 2026-08-28
- State: fixed and live
- Sources: L-0197, L-0233
