## Choices

### 17.1 Should a feel slider also be able to ask for the low end, such as the calmest or darkest tracks?

- **Today:** each feel slider keeps only the top part of the library (most intense, brightest, most tense, most acoustic); there is no way to ask for the calmest tracks.
- **Options:** A: high end only. B: each slider can ask for either end, for example calm or intense, with off in the middle.
- **Recommended:** B, since calm and dark beds under interviews are a common ask and it costs no extra control.
- **What you would notice:** with B an editor can ask for the calmest or darkest tracks directly.
- (music-Q1)

### 17.2 Should the library's upkeep happen on its own: analysing new and changed files, making listening copies, and removing tracks whose files have gone?

- **Today:** these are steps someone runs by hand at one studio computer; a removal that would take more than 5 tracks and a fifth of the library is held unless the person running it insists.
- **Options:** A: on their own, with a large removal held until an admin confirms it. B: kept as steps a person runs.
- **Recommended:** A, because a dropped track must need no further step and a gone file must leave search without anyone remembering to run something.
- **What you would notice:** with A nobody runs anything; an admin is asked only when a removal looks too large.
- (music-Q2)

### 17.3 Each track's loudness is measured; should it be shown on the track, or used as a filter?

- **Today:** loudness (integrated LUFS and peak) is measured for every track but never shown or filtered on. Your ruling requires it to be measured the same way everywhere, so dropping it is not an option.
- **Options:** A: measured, not shown. B: shown beside tempo and key on the track. C: shown and filterable like tempo.
- **Recommended:** B, since it is already measured and costs only a figure on the row.
- **What you would notice:** with B an editor sees how loud a track is before placing it; with C they can also narrow by it.
- (music-Q3)
