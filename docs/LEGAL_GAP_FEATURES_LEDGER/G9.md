1. **LG-1's markers are not replaced** (above). `EXPECTED_ENG_GAPS` is
   therefore not empty.
2. **TELEMETRY 8.4: "`config.validate_config` rejects it" became "rejects it
   when the address is saved".** G1a's departure 1: the error is raised only
   with `for_save=True`, because an error at start would stop the lanes.
   The plan's sentence would be false at start.

   wrote in a client folder's contact details, description and notes" (G3
   review point 4 / hand-off 3). `forget_shares` rewrites `created_by` and
   `added_by` only, and the free text may contain the person's name, so the
   paragraph's "the person's name ... replaced by a fixed stand-in" for
   client-folder entries would otherwise over-promise.

   dashboard")**, because LG-1 is not applied. Note J's answer (G1a, G2a)
   makes it apply only to computers whose companion predates the switches;
   the replacement below words it that way.
5. **Not edited: `onboarding/README.md`, `docs/SELF_DIAGNOSIS.md`, the
   plan's own §4.4 "600 s"**: none is a G9 file (hand-offs below).
