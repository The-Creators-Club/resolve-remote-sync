### L02-001: The editor's app vanished from the tray mid-edit and stayed gone
- What was going on: The app aborted with nothing logged, and Windows sign-in and a macOS login item each start a program once, so nothing brought it back.
- What the product must do: An app that dies unasked is relaunched within about 10 seconds, never after a quit, an upgrade or a deliberate stop, and at most three times an hour.
- Kind: 3
- Capability: editor-app
- Found by: real use
- Date: 2026-08-31
- State: fixed and live
- Sources: L-0102

### L02-002: A window toolkit object freed on the wrong thread killed the whole app
- What was going on: Freeing a window toolkit interpreter on any thread but its creator aborts the process with no traceback, and garbage-collected reference cycles free it on arbitrary threads.
- What the product must do: Every window toolkit interpreter is freed only on the thread that created it, proven by a test that closes a dialog and collects garbage on another thread.
- Kind: 1b
- Tool: Python's Tk binding (tkinter, Tcl_AsyncDelete abort)
- Capability: editor-app
- Found by: real use
- Date: 2026-08-31
- State: fixed and live
- Sources: L-0102
