for a new editor computer, or to repair one

The full clean-install and repair package for a new editor computer. Save it to that computer's own disk: running it off the shared drive locks the file for everyone, and the setup wizard refuses it.

On a phone: this package cannot be run here. Download it and send it to the editor's own computer, Windows or macOS, and run it there.

The menu's installer entry goes straight to the package for the browser's own platform, so the click is the download. This page only appears when the browser names neither Windows nor macOS, and for setting up the other platform (a Mac, from a Windows computer). The file keeps its version in its name, so "which installer did you run?" has an answer.
