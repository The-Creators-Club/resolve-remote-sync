# The sealed drawer

NOT part of the pack. These are lessons about tools and techniques the old build chose. The rebuild must choose its own, so it is shown none of this up front. Once its design is committed in writing and names a tool, it is given the one file for that tool, and never learns what else is here. A file named for two tools (`a+b`) is released only when both are named. The two `-facilities` files hold notes on parts of Windows and macOS themselves; each is released when the design reaches that platform.

Written by `tools/assemble_kb.py`; do not edit by hand.
