### H05-002: A redirect could replay the NAS admin password to another host.
- What was going on: A 307 or 308 redirect resends the request body unchanged, and custom key headers usually follow it; only the standard authorization header is dropped across hosts.
- What the product must do: No request carrying a password, key or session, from the server or an editor's computer, follows a redirect; a redirect is refused and named with its target.
