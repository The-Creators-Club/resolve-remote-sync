SEALED. Not part of the pack. Released to the rebuild only after its own committed design names this tool. 1 notes.

### SRV-S21: Cloud storage prices for about 3.4 TB of proxies and project files.
- Why: A 5 TB storage box cost 13 euros a month and another store about $20; one store bills deletions for 90 days, so unticking projects costs money.
- Must: Cloud backup cost is checked against data size and deletion rules; a store billing early deletion is unsuitable when projects are often dropped.
- Tool: Hetzner Storage Box, Backblaze B2, Wasabi
- Where it bit: The server: installing it and keeping it running
