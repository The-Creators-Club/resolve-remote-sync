# Knowledge base part C07

## Entries

### C07-001: The field SSD hung after about 300 GB of non-stop writing.
- What was going on: A portable SSD used for card backups on location hung three times, each after roughly 300 GB or 20-25 minutes of continuous writing.
- What the product must do: Long field copies must pause to let the drive rest (for example 10 minutes after every 150 GB), show that it is resting, and stay cancellable.
- Kind: 1a
- Capability: footage-sorter-and-camera-cards
- Found by: real use
- Date: 2026-10-15
- State: fixed, never shipped
- Sources: C-fs-b425357df

### C07-002: A hung target drive must not hang the card backup that writes to it.
- What was going on: When the field drive hung mid-copy, the copy sat without progress and the drive sometimes did not come back until it was unplugged and plugged in again.
- What the product must do: A copy with no progress for a set time is stopped, the person is told to replug if the drive stays gone, and the run resumes copying only what is missing.
- Kind: 3
- Capability: footage-sorter-and-camera-cards
- Found by: real use
- Date: 2026-10-15
- State: fixed, never shipped
- Sources: C-fs-10d56c2a9

### C07-003: A drive that stopped answering mid-check got 454 good copies marked bad.
- What was going on: The SSD hung during the after-copy check, every later file failed to read, and each was set aside as a bad copy although nothing was wrong with them.
- What the product must do: A read error during checking stops the check and says so; only a proven size or content mismatch ever marks a copy bad.
- Kind: 3
- Capability: footage-sorter-and-camera-cards
- Found by: real use
- Date: 2026-10-15

### C07-004: A stopped or resumed card copy left unchecked copies counted as safe.
- What was going on: Runs cancelled before their final check recorded what they had copied, and the next run skipped those files by name and size, so 29 clips were never checked.
- What the product must do: A copy counts as backed up only after its content matches the card (re-read from the card); a resumed run checks every earlier unchecked copy it skips.
- Kind: 3
- Capability: footage-sorter-and-camera-cards
- Found by: real use
- Date: 2026-10-15
- State: fixed, never shipped
- Sources: C-fs-cba358c2e, C-fs-29ab3856d, C-fs-0211f8ca7

### C07-005: The copy tool cannot check per job, and reports unchecked copies as still queued.

- What the product must do: Decide what landed by looking at the disk, not the copy tool's result, and restore the tool's global verify setting even after a crashed run.
- Kind: 1b
- Tool: TeraCopy 4.0.5 (global TestAlways setting, result code 2)

- Found by: real use
